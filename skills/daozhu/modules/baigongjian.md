# 百工鑑（工作調度）

## 核心心法
「因事擇道，因時換策，剛柔並濟，知行合一。」

## 觸發
- 自動：任務雷達偵測到「任務優化/規劃」需求（「該怎麼安排」「幫我規劃」「怎麼執行」），且非創作/開發類明確任務
- 手動：`@工 [任務]`
- 明確創作/開發任務（寫小說/做網站/做遊戲）仍路由到 `workflows/routing-workflow.md` 對應技能，不走百工鑑

## 四階段架構（所有任務通用）

| 階段 | 核心問題 | 預設思想 | 輸出 |
|------|---------|---------|------|
| 壹·定策 | 這件事的本質？該不該做？重點在哪？ | 道家＋兵家 | 心法→白話→第一步行動 |
| 貳·立法 | 具體怎麼做？時間、步驟、標準？ | 法家 | 時間與步驟→自我約束承諾 |
| 參·應變 | 遇到阻礙/他人/意外怎麼辦？ | 縱橫家＋儒家 | 預判阻礙→應對預案 |
| 肆·養心 | 如何保持動力、減少內耗、覆盤？ | 佛教＋墨家 | 內耗防護→覆盤提醒 |

## 輸出格式（強制）
```
【百工鑑·工作優化指南】
任務：[簡述]

壹·定策（源於道家與兵家）
· 心法：[一句對應原文]
· 白話：[對任務的具體理解]
· 第一步行動：[明確、具體的開頭動作]

貳·立法（源於法家）
· 心法：[如「循名責實，信賞必罰」]
· 時間與步驟：[具體時間區塊或里程碑]
· 自我約束：[具體紀律承諾]

參·應變（源於縱橫家與儒家）
· 心法：[「揣摩其情，因事而變」＋「己所不欲，勿施於人」]
· 可能的阻礙：[1-2 個最可能的困難]
· 應對預案：[具體做法]

肆·養心（源於佛教與墨家）
· 心法：[「念起即覺，覺已不隨」＋「以類取，以類予」]
· 內耗防護：[一句安慰＋一個自我照顧動作]
· 覆盤提醒：[何時、如何回顧]

總結一句：[≤15字總心法]
```

## 自動適應規則
| 任務特徵 | 調整方向 |
|---------|---------|
| 緊急（3天內死線） | 強化「立法」階段，步驟更細 |
| 涉及他人 | 強化「應變」階段，補充具體話術 |
| 完全不懂的領域 | 強化「定策」階段，增加兵家「五事」分析（`patches/military.md`） |
| 讓你極度焦慮 | 強化「養心」階段，佛教心法擴充至 50%（`patches/buddhist.md`） |
| 重複性高 | 強化「立法」階段，加入墨家「節用」效率工具（`patches/mohist.md`） |

## 程式開發專用擴充
觸發：問題含「寫code、程式、除錯、coding、debug」。
```
IDE 五階段映射：
定錨與佈局（道家＋兵家）→ 建構與紀律（法家＋墨家）→ 突圍與除錯（縱橫家＋兵家）
→ 溝通與協作（儒家＋名家）→ 靜心與自省（佛教＋道家）

除錯專用輸出：情勢研判（兵家五事）→ 正合之策（法家）→ 奇勝之策（縱橫家）→ 心法金句（佛教/道家）
```

## 指令速查
| 指令 | 功能 |
|------|------|
| `@工 [任務]` | 啟動百工鑑 |
| `@工 急 [任務]` | 緊急版（四階段各壓縮一句，總字數 ≤150） |
| `@工 深 [任務]` | 深度版（四階段各擴充完整段落，附經典原文出處） |
| `@工 程式 [任務]` | 強制啟用程式開發擴充 |
