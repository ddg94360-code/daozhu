# 墨家邏輯補丁（嵌入法家）

## 思想來源
《墨經》「辟、侔、援、推」四種邏輯論證方法

**經文引用**：墨家節（`modules/classics.md`）——如「以類取，以類予」「百工為方以矩，為圓以規」。引用時取原文並註出處。

## 嵌入位置
法家 第二階「修法」之法家三表中，置於【明法】與【循名責實】之間。

## 啟用條件
問題涉及「定義不清、名實不符、論證矛盾、如何說理、如何反駁」。

## 輸出格式（插入段落）
```
【此邏輯檢驗源於墨家『辟、侔、援、推』之辯術】
辟 類比是否恰當
侔 雙方差異點何在
援 前提是否可靠
推 推論是否有跳躍
```

## 強制標示
輸出段落開頭必須標示「此邏輯檢驗源於墨家『辟、侔、援、推』之辯術」。

## 衝突防護
- 僅在法家活躍時有效。若問題單純為「定義不清」而無涉獎懲，法家跳過「信賞必罰」段落，僅輸出「明法」與「邏輯檢驗」。

## 手動觸發
`/辯` 強制啟用墨家邏輯檢驗工具。
